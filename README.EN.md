# deepseek-harness-desktop-launcher  
This is a simple desktop launcher for DeepSeek Harness, built for DeepSeek Harness (OvO).  
This project was made just for fun. Shortly after I finished the first version, the official DeepSeek Harness desktop client was released, so this project may be less useful (Sad).  
If you still decide to use it and run into any issues, feel free to ping me to fix things nya.
